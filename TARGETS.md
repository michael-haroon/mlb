Totals
    - Winner and loser, as probabilities, two markets, independent yet give same exposure. get the cheaper one (eg. yes team A vs no team B are the same but one is often cheaper)
    - Spread
        - Team A/B wins by over X runs, where X is in the set of halfway points between natural numbers incrememnted by 1 (1.5, 2.5, 3.5,...)
    - Total runs
        - Over X runs scores, where X is liek that in spread
    - Team totals
        - Team A over X runs scored

Game Lines
    - Spread in first 5 innings
        - Team A -X first 5 innings where it Resolves Yes if team A wins by more than X runs in the first 5 innings, where X is defined like in Spread
    - Point total in first 5 inning
        - Over X runs in the first 5 innings
    - YRFI/NRFI (run first inning)
        - Resolves Yes if either team scores a run in the first inning
    - First 5 innings winner
        - Team A wins, team B wins, or tie
Player props
    - Home runs per player (eg. player A 1+ home run yes or no) 
    - Strikeouts per player
    - Hits per player
    - Hits + runs + rbis per player
    - total bases per player
